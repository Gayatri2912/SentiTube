## Component Details

### Source Code (`src/`)

#### `config.py`
- Centralized configuration
- Path definitions
- Parameter loading from `params.yaml`

#### `data_ingestion.py`
- Generates synthetic YouTube comments dataset
- Can be replaced with real YouTube API integration
- Outputs: `data/raw/youtube_comments.csv`

#### `data_preprocessing.py`
- Text cleaning (URLs, mentions, hashtags removal)
- Tokenization and lemmatization
- Stopword removal
- Outputs: `data/processed/preprocessed_data.csv`

#### `feature_engineering.py`
- TF-IDF vectorization (5000 features, bigrams)
- Additional features (text length, word count, etc.)
- Train-test split
- SMOTE for handling imbalanced data
- Outputs: `data/processed/features.pkl`, `models/vectorizer.pkl`

#### `model_training.py`
- Trains 3 models: Random Forest, XGBoost, LightGBM
- MLflow experiment tracking
- Logs parameters, metrics, and models
- Outputs: Model files in `models/`

#### `model_evaluation.py`
- Compares all trained models
- Generates confusion matrices
- Selects best model based on F1 macro score
- Outputs: `models/best_model.pkl`, `metrics/evaluation_results.json`

#### `prediction.py`
- SentimentPredictor class
- Text preprocessing
- Feature extraction
- Prediction with confidence scores

### Web Application (`app/`)

#### `app.py`
- Flask REST API
- Endpoints: `/health`, `/predict`, `/predict_batch`
- CORS enabled
- Error handling

#### `templates/index.html`
- Modern, responsive web interface
- Real-time sentiment analysis
- Probability distribution visualization
- Gradient UI with animations
